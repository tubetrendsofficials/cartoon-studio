# Cartoon Studio — 2D Animation Maker

ব্রাউজারেই চলা, সম্পূর্ণ ফ্রি ও অফলাইন-ফার্স্ট **2D কার্টুন অ্যানিমেশন স্টুডিও**। YouTube-এর জন্য কার্টুন গল্পের ভিডিও বানানোর ওয়েব অ্যাপ — কোনো সার্ভার লাগে না, প্রজেক্ট সেভ থাকে আপনার ব্রাউজারের IndexedDB-তে।

> এটি একটি সম্পূর্ণ নিজস্ব (original) প্রজেক্ট। ফিচারের অনুপ্রেরণা একটি রেফারেন্স সাইট থেকে এলেও এর কোড, ছবি, ক্যারেক্টার ও লেখা — সবই এই রিপোতে নতুন করে বানানো।

## 🔴 লাইভ সাইট: https://tubetrendsofficials.github.io/cartoon-studio/

অ্যাপটি এখন **GitHub Pages-এ লাইভ** (v0.10.3) — লিংকে ক্লিক করলেই ব্রাউজারে চলবে, কিছু ইনস্টল করতে হবে না। ২০২৬-১১-১৩ তারিখে আসল ব্রাউজারে পুরো যাচাই করা হয়েছে: ড্যাশবোর্ড, প্রজেক্ট তৈরি/সেভ (রিলোডের পরেও থাকে), ক্যারেক্টার/ব্যাকগ্রাউন্ড/প্রপ যোগ, প্লেব্যাক, আর পূর্ণ **720p WebM ভিডিও এক্সপোর্ট**।

## যা যা আছে (বর্তমান অবস্থা)

**বিল্ড স্ট্যাটাস: Phases 0–10 complete — অ্যাপ GitHub Pages-এ LIVE (v0.10.3) ও আসল ব্রাউজারে যাচাই করা** ✅

- ✅ **Phase 0 — রিপো কঙ্কাল + PWA:** অ্যাপ শেল, ডার্ক থিম (navy `#101a30`), `manifest.json`, সার্ভিস ওয়ার্কার (অফলাইন ক্যাশ), আইকন, GitHub Pages workflow
- ✅ **Phase 1 — ড্যাশবোর্ড + প্রজেক্ট সিস্টেম:** প্রোফাইল কার্ড (Local Creator, FREE ব্যাজ), আসল storage মিটার, প্রজেক্ট সার্চ, সঙ্গে-সঙ্গে নতুন প্রজেক্ট (কোনো ডায়ালগ ছাড়া), Rename / Duplicate / Delete / Open, `.cartoon.json` Export/Import, অটো-সেভ, প্রথমবারের জন্য একটি **Sample**-লেবেলযুক্ত নমুনা প্রজেক্ট
- ✅ **Phase 2 — এডিটর কোর:** আসল এডিটর — 16:9 ক্যানভাস স্টেজ (লেয়ার আঁকা, সিলেক্ট/ড্র্যাগ, জুম, Hand/pan, Camera framing গাইড), বামে 12 প্যানেলের রেল + ড্রয়ার (Character ড্রয়ারে Phase-2 টেস্টের জন্য **Sample**-লেবেলযুক্ত 3টি নমুনা লেয়ার; বাকি ড্রয়ারে কোন ধাপে আসল টুল আসবে তা সৎভাবে লেখা), টাইমলাইন (রুলার, প্লেহেড ড্র্যাগ/সিক, Play/Pause, ∓5s, ক্লিপ সরানো/রিসাইজ, লেয়ার সারি — Up/Down, Hide, Lock, Remove, Options), দ্বিতীয় টুলবার (Duplicate, Split, Camera লেয়ার, Undo/Redo, সিন বাছাই + Add Scene), সিনভিত্তিক টাইমলাইন (রুলার সক্রিয় সিনের দৈর্ঘ্য দেখায়), Ctrl+Z/Y।
- ✅ **Phase 3 — অ্যাসেট কারখানা v1:** নিজে আঁকা আসল SVG লাইব্রেরি (`assets/`, তালিকা `assets/manifest.json`) — **12টি ক্যারেক্টার × 6 পোজ** (Stand/Walk/Talk/Sit/Wave/Point), **10টি ব্যাকগ্রাউন্ড**, **20টি প্রপস**। Character ড্রয়ারে সার্চ + পোজ পিকার + Flip + Mouth মোড (Idle/Talk/Look Behind), Media ড্রয়ারে ব্যাকগ্রাউন্ড গ্রিড (ক্লিকে সিনের ব্যাকগ্রাউন্ড বসে/বদলায়), Asset Library ড্রয়ারে প্রপস গ্রিড। পুরো লাইব্রেরি ফ্রি ও read-only।
- ✅ **Phase 4 — অ্যানিমেশন ইঞ্জিন:** **AI Animate** 6টি প্রিসেট (Gentle Float, Bounce Hop, Breathing, Wave Hello, Walk Step, Surprise Shake — পোজ-সাইক্লিংসহ, টাইমলাইন ক্লিপে ব্যাজ দেখায়), **Motion Path** (ক্যানভাসে ক্লিকে সর্বোচ্চ 5 পয়েন্ট, ড্র্যাগে ঠিক করা, Easing: Linear/Ease In-Out/Ease Out), **Animation Speed** 0.25×–3× (প্রিসেট চিপ + স্লাইডার), **Talk মুখ-নাড়া** (চলার সময় ~6 Hz-এ Talk/Stand পোজ বদলায় — timed flap; Phase 5-এর ভয়েস ট্র্যাক বাজলে তার সঙ্গেই নাড়ে), **Camera কীফ্রেম** (Edit View-তে প্যান/জুম সেট করে Playhead-এ কীফ্রেম; প্লেব্যাকে পুরো স্টেজে আসল ক্যামেরা মুভমেন্ট), **সিন ট্রানজিশন** Cut/Fade + প্লেব্যাক শেষ সিন থেকে পরের সিনে নিজে নিজে এগিয়ে যায় (Fade-এ 300ms ফেড)। অ্যানিমেশনের সব গণিত `js/anim.js`-এ (pure ফাংশন, Node-এ টেস্ট করা)।
- ✅ **Phase 5 — অডিও স্যুট:** **মাইক ভয়েস রেকর্ডিং** (MediaRecorder, WebM — লাইভ টাইমার + লেভেল মিটার; থামালেই প্লেহেডে ওয়েভফর্মসহ বেগুনি অডিও ট্র্যাক), **Media অডিও লাইব্রেরি** (রেকর্ডিং / আপলোড / SFX — প্রিভিউ, টাইমলাইনে যোগ, Delete; সব ফাইল IndexedDB-র media স্টোরে লোকাল), **অডিও আপলোড**, **Sounds প্যানেলে Web Audio দিয়ে তৈরি 5টি SFX** (Rain, Birds, Wind, Thunder, River — Generate করলে WAV হিসেবে লাইব্রেরিতে সেভ হয়, পরে পুনঃব্যবহার), **অডিও ক্লিপ Trim** (ডান ধার = দৈর্ঘ্য, বাম ধার = সোর্স offsetসহ), **Volume স্লাইডার + Mute**, আর **প্লেহেডের সঙ্গে সিঙ্ক প্লেব্যাক** (Play/Pause/Seek/সিন বদলে অডিও ঠিক জায়গা থেকে বাজে)। মুছে ফেলা মিডিয়ার ক্লিপ "MISSING MEDIA" চিহ্নিত হয়ে নীরবে স্কিপ হয়। ⚠️ **সীমাবদ্ধতা:** অডিও ফাইল প্রজেক্ট JSON-এ থাকে না — শুধু media id থাকে; তাই `.cartoon.json` এক্সপোর্টে একটি `mediaManifest` নোট থাকে — *"audio media is stored locally in this browser"* — অন্য ব্রাউজারে সেই ক্লিপগুলো লাইব্রেরিতে আবার যোগ না করা পর্যন্ত "missing media" দেখাবে।
- ✅ **Phase 6A — স্পেশাল টুলস (পার্ট 1):** **Local প্যানেল** — অফলাইন আপলোড গ্যালারি (ছবি/ভিডিও/অডিও/GIF/স্প্রাইট শিট; ফিল্টার: All/Images/Videos/Audios/GIFs/Sprite Sheets; সবকিছু শুধু এই ডিভাইসের IndexedDB-তে থাকে, কোথাও আপলোড হয় না)। ছবি → **image লেয়ার**, ভিডিও → **video লেয়ার** (প্লেহেডের সঙ্গে সিঙ্ক; ক্লিপের চেয়ে ছোট হলে ক্লিপের ভিতরে লুপ করে), **Sprite Sheet Studio** — শিট আপলোড → Columns/Rows/Frames/FPS দিয়ে কাটা, Onion Skinসহ লাইভ প্রিভিউ, "Save as Character" → **sprite লেয়ার** (fps অনুযায়ী ফ্রেম চলে), **White Background Remover** (Anim IK প্যানেলে — Key Colour পিক + Range + Edge Softness, Checkerboard প্রিভিউ, Transparent PNG ডাউনলোড / সিনে যোগ; সম্পূর্ণ অফলাইন), **Eraser** (GOTO Edit-এর সমতুল্য — Eraser/Restore ব্রাশ, সাইজ + Hardness, Undo ≤10 ধাপ, Transparent PNG; "Offline Ready"), **Effect Studio** — 6টি **effect লেয়ার** (Rain — 3 intensity + Lightning, River + মাছ, Birds, Leaves, Sparkle, Clouds; সব পার্টিকল সিন-টাইমের deterministic ফাংশন, তাই স্ক্রাব করলেও ফ্রেম হুবহু এক)। ⚠️ **সীমাবদ্ধতা:** অ্যানিমেটেড GIF লেয়ার Chrome/Firefox-এ চলমান ফ্রেম দেখায়, কিছু ব্রাউজারে স্থির প্রথম ফ্রেম দেখাতে পারে; ভিডিও লেয়ার নিঃশব্দে চলে (শব্দের জন্য অডিও ট্র্যাক আলাদা); বড় ছবি টুলগুলোতে সর্বোচ্চ 1600px working copy-তে প্রসেস হয়।
- ✅ **Phase 6B — স্পেশাল টুলস (পার্ট 2):** **Character Studio** (রেফারেন্সে Pro-গেটেড — আমাদের এখানে সম্পূর্ণ **ফ্রি**): parametric ক্যারেক্টার বিল্ডার (`js/charbuilder.js`) — নাম, গায়ের রং (৫টি), চুলের স্টাইল (৯টি: ছোট/খাড়া/খোঁপা/লম্বা/টুপি/ক্যাপ/গামছা/ফিতা/টাক) ও রং, দাড়ি, চশমা, পোশাক (পাঞ্জাবি/শার্ট/শাড়ি/ফ্রক/ইউনিফর্ম/ভেস্ট) ও নিচের পোশাক (লুঙ্গি/পাজামা/প্যান্ট/শর্টস/স্কার্ট), অ্যাক্সেসরি (লাঠি/বই/গামছা/অ্যাপ্রন) — প্রতিটি সেভ করা ক্যারেক্টার **৭টি পোজে** (Stand/Walk/Talk/Sit/Wave/Point/Back) তৈরি হয়, লাইভ প্রিভিউসহ; সেভ থাকে IndexedDB media স্টোরে (“My Characters” — Studio ও Character দুই প্যানেলেই; Edit/Add/Delete)। লাইব্রেরি ক্যারেক্টারের মতোই পোজ চিপ, Mouth মোড, Flip, AI Animate প্রিসেট ও Motion Path কাস্টম ক্যারেক্টারেও হুবহু কাজ করে; মুছে ফেললে লেয়ারে “MISSING MEDIA” ফ্ল্যাগ ওঠে। **Adjust & Mask:** যেকোনো ভিজ্যুয়াল লেয়ারে Brightness/Contrast/Saturation/Opacity স্লাইডার + Mood প্রিসেট (Warm/Cool/Vintage/Mono) + Reset, আর Mask (None/Rectangle/Rounded/Squircle/Circle/Star/Heart — ক্যানভাসে clip)। **Wearables:** ক্যারেক্টারের গায়ে পরানো প্রপস (সানগ্লাস, ক্যাপ, মুকুট, হেডফোন, পার্টি টুপি, জাদুর কাঠি) — লেয়ারের সঙ্গে ফ্লিপ হয়, লাইব্রেরি + কাস্টম দুটোতেই চলে। **Tutorial প্যানেল:** অ্যাপে বান্ডল করা ৬টি বাংলা ধাপ-গাইড (অফলাইন)। **Cinema প্যানেল:** বোন-সাইট GoToCinema-তে লিংক কার্ড (সাইটটি আলাদা, এই স্টুডিওর অংশ নয়)। এছাড়া ট্র্যাক সারিতে Bring to Front / Send to Back, ক্যারেক্টার টুলসে Delete ও Studio-খোলার বোতাম, ক্যানভাসে ক্যারেক্টারে ডাবল-ক্লিকে Studio খোলে।
- ✅ **Phase 7 — ভিডিও এক্সপোর্ট:** Export ডায়ালগে **720p HD (1280×720, 30fps)** অথবা **1080p Full HD (1920×1080, 30/60fps)** — ঠিক রেফারেন্সের মতো অপশন। এক্সপোর্ট চলে **এডিটরের নিজের ক্যানভাস দিয়েই** (export মোডে রেজোলিউশন অনুযায়ী রেন্ডার; সিলেকশন/নাম-লেবেলের মতো এডিটর-সাহায্যগুলো ফ্রেমে আসে না), তাই অ্যাসেট, কাস্টম ক্যারেক্টার, স্প্রাইট, ভিডিও লেয়ার, এফেক্ট, ক্যামেরা ও ট্রানজিশন — সব হুবহু প্রিভিউয়ের মতোই আসে। **WebM** (MediaRecorder + canvas capture; অডিও ট্র্যাক থাকলে অডিও ইঞ্জিনের মিক্সও একই ফাইলে) — সম্পূর্ণ অফলাইন। **MP4** চাইলে ffmpeg.wasm CDN থেকে লেজি-লোড হয় (শুধু MP4 বাছলেই; একবার ~31 MB ডাউনলোড — ডায়ালগে আগেই পরিষ্কার লেখা থাকে), libx264 + AAC-তে কনভার্ট হয়; ব্যর্থ হলে WebM ডাউনলোড থেকেই যায়। প্রগ্রেস বার + Cancel আছে, **কোনো ওয়াটারমার্ক নেই — সব ফ্রি**। ⚠️ এক্সপোর্ট **রিয়েল-টাইমে** রেকর্ড হয় (প্রজেক্ট যত লম্বা, এক্সপোর্ট ততক্ষণ) — ট্যাবটি সামনে রেখে দিতে হয়।
- ✅ **Phase 8 — আমাদের বাড়তি সুবিধা (রেফারেন্সে নেই):** **Text টুল** — দ্বিতীয় টুলবারে “+ Text”: ক্যানভাসে আসল wrapped টেক্সট (Plain/Title/**Bubble** স্টাইল — বাবল মানে সাদা গোল বাক্সে সংলাপ), রঙের swatch + নিজের রঙ, Bold, Align, সাইজ 24–160; ড্র্যাগ, AI Animate প্রিসেট/পাথ, Adjust — সবই অন্য লেয়ারের মতো চলে। **সাবটাইটেল লেয়ার** — “+ Subtitle”: স্টেজের একদম নিচে fixed (টানা যায় না), আধা-স্বচ্ছ কালো বারের উপর সাদা লেখা; ক্লিপ পরপর সাজালেই dialogue track। **9:16 ও 1:1 প্রজেক্ট** — ড্যাশবোর্ডে New Project-এর পাশে aspect picker (16:9 · 9:16 Shorts · 1:1); **aspect প্রজেক্ট তৈরির সময়েই ঠিক হয়, পরে বদলানো যায় না** — কার্ডে aspect ব্যাজ থাকে, এডিটরের সব মাপ (স্টেজ, ক্যামেরা, সেফ-এরিয়া, ইফেক্ট) ও এক্সপোর্ট প্রিসেট aspect অনুযায়ী হয় (9:16 → 720×1280/1080×1920, 1:1 → 960×960/1080×1080)। **TTS প্রিভিউ** — Web Speech API: বাংলা/ইংরেজি ভয়েস সবার আগে, rate 0.5–2×, Speak বোতাম, চাইলে প্রিভিউ প্লেব্যাকে auto-speak। ⚠️ **TTS শুধু প্রিভিউয়ের সাহায্য — কম্পিউটার ভয়েস এক্সপোর্ট করা ভিডিওতে রেকর্ড হয় না** (এক্সপোর্টের সময় TTS পুরোপুরি বন্ধ থাকে); ফাইনাল ভিডিওতে নিজের ভয়েস চাইলে Voice টুলে (Phase 5) রেকর্ড করুন।

## লোকালি চালানো

কোনো বিল্ড-স্টেপ নেই — যেকোনো স্ট্যাটিক সার্ভারেই চলবে:

```bash
# এই ফোল্ডারে এসে
python3 -m http.server 8000
# তারপর ব্রাউজারে খুলুন: http://localhost:8000
```

অথবা `npx serve .` ব্যবহার করুন। (সরাসরি `file://` দিয়ে খুললেও ড্যাশবোর্ড চলবে, তবে PWA/অফলাইন ক্যাশের জন্য http সার্ভার ভালো।)

## GitHub Pages-এ ফ্রি ডিপ্লয়

1. এই রিপোটি GitHub-এ push করুন (`main` ব্রাঞ্চ)।
2. Repo-র **Settings → Pages**-এ যান।
3. **Build and deployment → Source: GitHub Actions** বেছে নিন।
4. `.github/workflows/pages.yml` workflow-টি প্রতিটা push-এ সাইটটি অটো-ডিপ্লয় করবে — লাইভ লিংক হবে `https://<username>.github.io/<repo>/`।

**🔴 Live site: https://tubetrendsofficials.github.io/cartoon-studio/** — v0.10.2, live-verified in a real browser on 2026-11-13 (dashboard, project persistence across reload, character/background/prop adds, playback, and a complete 720p WebM export all confirmed working).

- **Run locally:** `python3 -m http.server 8000` in this folder, then open `http://localhost:8000`.
- **Deploy free:** push to GitHub, set **Settings → Pages → Source: GitHub Actions**; the included workflow deploys on every push to `main`.
- **Status:** Phases 0–10 complete — LIVE on GitHub Pages as v0.10.2 and live-verified in a real browser on 2026-11-13 (skeleton, PWA, dashboard + project system, editor core with canvas stage, timeline, layers and scenes, the original SVG asset factory: 34 characters — all 33 reference roles covered (30 people × 7 poses including a true Back pose, plus a bus, a puppy and a parrot with variant poses) plus one extra entry, Mishuk the auto rickshaw — 21 backgrounds (two of them combo packs with 2 scene variants each), 49 props in `assets/`, the animation engine: 6 AI Animate presets, motion paths with easing, animation speed, Talk mouth flap, camera keyframes and Cut/Fade scene transitions with auto-advance playback, the audio suite: microphone voice recording (WebM) with waveform audio tracks, a local audio library (recordings / uploads / generated SFX in IndexedDB), eleven Web-Audio-synthesized sound effects — Rain, Birds, Wind, Thunder, River, Sheep, Rooster, Cat, Frog, Farm Mix and a 36-second Morning Birds dawn chorus — clip trim/volume/mute, and playhead-synced playback, the special tools part 1: an offline Local uploads gallery with image/video/GIF layers — video layers sync to the playhead and loop inside their clip when shorter;

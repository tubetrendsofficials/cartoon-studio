# আমাদের 2D কার্টুন অ্যানিমেশন স্টুডিও — ধাপে ধাপে পুরো বিল্ড প্ল্যান

লক্ষ্য: gotoanimation.com-এর **সব ফিচার ও টুলসের সমমানের** একটি নিজস্ব ওয়েব অ্যাপ —
GitHub-এ কোড, GitHub Pages-এ সম্পূর্ণ ফ্রি হোস্টিং, ব্রাউজারেই অ্যানিমেশন ভিডিও বানানো ও এক্সপোর্ট।
ভিত্তি রিপোর্ট: `A-TO-Z-REPORT.md` (আসল সাইটের যাচাই করা ফিচার তালিকা)।

## মূল নীতি (শুরু থেকেই ঠিক করা)
1. **নিজস্ব কোড ও নিজস্ব আঁকা অ্যাসেট** — আসল সাইটের কোড/ছবি/ক্যারেক্টার কপি নয়; ফিচার ও ধরনে হুবহু সমমান।
2. **সম্পূর্ণ ফ্রি স্ট্যাক** — কোনো সার্ভার নেই; স্ট্যাটিক ওয়েব অ্যাপ। হোস্টিং GitHub Pages (ফ্রি), প্রজেক্ট সেভ ব্রাউজারের IndexedDB-তে (offline-first, ওদের মতোই)।
3. **বিল্ড-স্টেপ ছাড়া** — plain HTML/CSS/JavaScript (ES modules)। ফলে GitHub-এ push করলেই Pages-এ লাইভ; কোনো কম্পাইল/সার্ভার ঝামেলা নেই।
4. প্রতিটা ধাপ শেষে **ব্রাউজারে চালিয়ে যাচাই** — শুধু কোড লিখে "হয়ে গেছে" বলা হবে না।
5. অ্যাসেটে যা নমুনা/ডেমো থাকবে তা অ্যাপে "Sample" লেবেলসহ থাকবে (পরে আসল দিয়ে বদলানো যাবে)।

## টেক স্ট্যাক (চূড়ান্ত)
| অংশ | প্রযুক্তি | কেন |
|---|---|---|
| অ্যাপ | Vanilla JS + HTML5 Canvas 2D | ফ্রি, হালকা, Pages-এ সরাসরি চলে |
| স্টেজ রেন্ডার | Canvas (লেয়ারড স্প্রাইট/SVG → Image) | ওদের মতো লেয়ার-ভিত্তিক 2D |
| ডেটা | Project JSON মডেল + IndexedDB সেভ + অটো-সেভ | অফলাইনেও প্রজেক্ট থাকে |
| অডিও | Web Audio API + MediaRecorder (মাইক, WebM) | রেকর্ড + ওয়েভফর্ম + মিক্স |
| ভিডিও এক্সপোর্ট | Phase A: canvas.captureStream + MediaRecorder → WebM (720p/1080p) · Phase B: ffmpeg.wasm → MP4 | ব্রাউজারেই ফ্রি এক্সপোর্ট |
| PWA | manifest.json + service worker (ক্যাশ) | ইন্সটল করা যায়, অফলাইন চলে |
| হোস্টিং | GitHub repo + GitHub Pages + Actions workflow | শূন্য খরচ |
| (ঐচ্ছিক, পরে) | Firebase (Google লগইন + ক্লাউড সিঙ্ক) | ওদের মতো মাল্টি-ডিভাইস সিঙ্ক চাইলে |

## ধাপসমূহ

### ধাপ 0 — রিপো ও কঙ্কাল
- ফোল্ডার গঠন: `index.html`, `css/`, `js/` (app, editor, timeline, assets, audio, export মডিউল), `assets/` (SVG ক্যারেক্টার/ব্যাকগ্রাউন্ড/প্রপস), `icons/`, `manifest.json`, `sw.js`, `README.md` (বাংলা ব্যবহার-নির্দেশিকা), `.github/workflows/pages.yml`।
- Git init + প্রথম কমিট (লোকাল)। GitHub-এ push এই ধাপের শেষে — **আপনার GitHub লগইন লাগবে তখন** (এখনো কানেক্ট হয়নি)।
- যাচাই: লোকাল সার্ভারে খালি অ্যাপ শেল ব্রাউজারে খোলে।

### ধাপ 1 — ড্যাশবোর্ড + প্রজেক্ট সিস্টেম
- প্রোফাইল/ড্যাশবোর্ড স্ক্রিন (ওদের ধাঁচে): Projects তালিকা, সার্চ, storage মিটার (IndexedDB-র আসল হিসাব)।
- New Project = সঙ্গে সঙ্গে ফাঁকা প্রজেক্ট (16:9, 2:00 টাইমলাইন), Rename / Duplicate / Delete / Open।
- প্রজেক্ট ফাইল Export/Import (আমাদের `.cartoon.json` ফরম্যাট)।
- যাচাই: প্রজেক্ট বানিয়ে, পেজ রিলোড দিলেও থাকে (অটো-সেভ)।

### ধাপ 2 — এডিটর কোর
- হেডার: প্রজেক্ট নাম (এডিটেবল), Auto-saved, Save, Export, প্রোফাইল।
- ক্যানভাস স্টেজ: 16:9, জুম, Hand/pan, Camera framing + safe-area গাইড।
- টাইমলাইন: প্লেহেড, ∓5s, Play/Pause, মোট দৈর্ঘ্য বদলানো, লেয়ার সারি (Move Up/Down, Hide, Lock, Remove)।
- বামে 12 প্যানেলের খালি কাঠামো (পরের ধাপে ভরা হবে), দ্বিতীয় টুলবার (Duplicate, Split, Undo, Redo)।
- যাচাই: ফাঁকা প্রজেক্টে প্লে চলে, Undo/Redo কাজ করে।

### ধাপ 3 — অ্যাসেট কারখানা v1 (ক্যারেক্টার + ব্যাকগ্রাউন্ড + প্রপস)
সব SVG-তে নিজে আঁকা, "Sample" লেবেলসহ:
- **ক্যারেক্টার কোর সেট (12টি):** গ্রামের যুবক, যুবতী, দাদু, বুড়িমা, পুলিশ, বাচ্চা ছেলে, বাচ্চা মেয়ে, দোকানদার, কৃষক, মোল্লা, রাজা, অটো-রিকশা চালক (+ রিকশা/বাস যান, কুকুর, তোতা)।
  প্রতিটি: পোজ — Standing/Idle, Sitting, Walking (2-ফ্রেম), Back; মুখ — Idle/Talk (মুখ নড়া)/Look Behind।
- **ব্যাকগ্রাউন্ড (10টি):** গ্রামের রাস্তা, উঠোন, চায়ের দোকান, ঘরের ভিতর, নদীর পাড়, ধানক্ষেত, বাজার, শহরের রাস্তা, স্কুল, আকাশ/মাঠ।
- **প্রপস (20টি):** গাছ, কলাগাছ, টেবিল, চেয়ার, চায়ের কাপ, ঝুড়ি, লণ্ঠন, বই, ছাতা, সানগ্লাস, টুপি, মুকুট, হেডফোন, জাদুর কাঠি ইত্যাদি।
- প্যানেলে ক্লিক/ড্র্যাগে ক্যানভাসে যোগ; সিলেক্ট হলে টুলবার: Flip, Speed, Mask, Adjust (Brightness/Contrast/Saturation/Opacity), Props পরানো, লেয়ার অর্ডার, Delete।
- যাচাই: ব্যাকগ্রাউন্ড + 2 ক্যারেক্টার বসিয়ে সিন সাজানো যায়।

### ধাপ 4 — অ্যানিমেশন ইঞ্জিন
- **AI Animate প্রিসেট (6টি, ওদের নামের ধরনে):** Gentle Float, Bounce Hop, Breathing, Wave Hello, Walk Step, Surprise Shake।
- **Motion Path:** ক্যারেক্টার সিলেক্ট করে গন্তব্যে ক্লিক/ড্র্যাগ — পথ ধরে চলা (ইজিংসহ)।
- Speed কন্ট্রোল (0.25x–3x), মুখের Talk মোড (অডিও চললে মুখ নড়ে)।
- Scenes: Add Scene, সিনের দৈর্ঘ্য, সিন বদল, সহজ ট্রানজিশন (Fade/Cut)।
- Camera লেয়ার: প্যান/জুম কীফ্রেম (সহজ সংস্করণ)।
- যাচাই: 2-সিনের ছোট গল্প প্লে করে পুরোটা দেখা যায়।

### ধাপ 5 — অডিও স্যুট
- মাইক রেকর্ডিং (WebM) → ওয়েভফর্মসহ অডিও ট্র্যাক।
- Media Audio লাইব্রেরি + নিজের অডিও আপলোড (Cloud নয় — IndexedDB-তে লোকাল)।
- Sounds প্যানেল: Web Audio দিয়ে তৈরি বেসিক এফেক্ট (বৃষ্টি, পাখির কিচিরমিচির, বাতাস) + আপলোড করা SFX।
- অডিও ট্র্যাকে Trim/ভলিউম, প্লেহেডের সঙ্গে সিঙ্ক।
- যাচাই: ভয়েস রেকর্ড করে ক্যারেক্টারের Talk মোডে চালানো।

### ধাপ 6 — স্পেশাল টুলস (ওদের বাকি প্যানেলগুলো)
- **Sprite Sheet Studio:** ফ্রেম/PNG শিট আপলোড, FPS/স্পিড, Onion skin, লাইভ প্লেয়ার, টাইমলাইনে যোগ, ক্যারেক্টার হিসেবে সেভ।
- **White BG Remover (Anim IK-এর বদলি কাজ):** ছবি/ভিডিও ফ্রেম থেকে সাদা/একরঙা ব্যাকগ্রাউন্ড তোলা (রেঞ্জ + এজ সফটনেস), Transparent PNG/WebM।
- **Eraser (GOTO Edit-এর মতো):** ছবিতে ইরেজার/ফেদার/ল্যাসো, Transparent PNG ডাউনলোড, "Offline Ready"।
- **Effect Studio:** বৃষ্টি (3 মাত্রা + বজ্রপাত), নদীর পানি ও মাছ, পাখির ঝাঁক (পথ আঁকা), পাতা/ডাল মোশন (Wind/Sway/Leaves/Cloud/Water/Sparkle প্রিসেট) — সব ক্যানভাস পার্টিকল দিয়ে।
- **Local প্যানেল:** অফলাইন আপলোড গ্যালারি (ছবি/ভিডিও/অডিও/GIF/স্প্রাইট)।
- **Tutorial প্যানেল:** নিজস্ব বাংলা গাইড ভিডিও/ধাপের জায়গা (প্রথমে টেক্সট গাইড)।
- যাচাই: প্রতিটা টুল থেকে অন্তত একবার টাইমলাইনে কিছু পাঠানো।

### ধাপ 7 — এক্সপোর্ট
- Export ডায়ালগ: 720p (1280×720, 30fps) / 1080p (1920×1080, 30/60fps) — ওদের মতোই 2 অপশন।
- Phase A: WebM ডাউনলোড (অডিও মিক্সসহ)। Phase B: ffmpeg.wasm দিয়ে MP4।
- প্রগ্রেস বার + ক্যানসেল।
- যাচাই: 20 সেকেন্ডের প্রজেক্ট এক্সপোর্ট করে ভিডিও প্লেয়ারে চালিয়ে দেখা (শব্দসহ)।

### ধাপ 8 — আমাদের বাড়তি সুবিধা (ওদের নেই)
- **Text টুল** (টাইটেল/ডায়ালগ বাবল), **সাবটাইটেল** লেয়ার, **9:16 ও 1:1** প্রজেক্ট (Shorts/Reels), **TTS প্রিভিউ** (ব্রাউজারের বিল্ট-ইন ভয়েস, ফ্রি)।
- যাচাই: একটা 9:16 Shorts প্রজেক্ট বানিয়ে এক্সপোর্ট।

### ধাপ 9 — GitHub রিলিজ
- GitHub-এ repo তৈরি ও push (**আপনার GitHub লগইন এখানে লাগবে**), Pages চালু, লাইভ লিংক যাচাই (মোবাইল + ডেস্কটপ)।
- README-তে বাংলা নির্দেশিকা + স্ক্রিনশট।
- যাচাই: লাইভ লিংক থেকে প্রজেক্ট বানিয়ে এক্সপোর্ট।

### ধাপ 10 — সম্প্রসারণ (চলমান)
- অ্যাসেট সংখ্যা ওদের সমান করা: ক্যারেক্টার 33, ব্যাকগ্রাউন্ড 21, প্রপস/অ্যাসেট 49 + আরও পোজ।
- Character Studio পূর্ণ সংস্করণ (নতুন পোজ আঁকা/রিগ)।
- (ঐচ্ছিক) Firebase দিয়ে Google লগইন + ক্লাউড সিঙ্ক; (ঐচ্ছিক) আপনার Gemini key দিয়ে AI ক্যারেক্টার/ব্যাকগ্রাউন্ড ছবি জেনারেশন।

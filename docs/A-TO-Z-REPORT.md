2. **Media** — Backgrounds 21টি (Single 19 + Combo Pack 2; গ্রাম/রাস্তা/দোকানের থাম্বনেইল) + নিজের ব্যাকগ্রাউন্ড আপলোড; Audio লাইব্রেরি (আগে থেকে তৈরি WAV ফাইল, mp3; Cloudinary-তে আপলোড)।
3. **Local** — এই ডিভাইসে অফলাইনে রাখা আপলোড (ছবি/ভিডিও/অডিও/GIF/স্প্রাইট শিট), ফিল্টারসহ; "সব আপলোড অফলাইনে অটো সেভ"।

5. **Studio** — Character Studio (রিগিং/নতুন পোজ) — Pro ছাড়া ঢোকা যায় না।
6. **Asset Library** — 49টি অ্যাসেট/প্রপস (আগুনের GIF, Walking Cycle, গাছের GIF, Pinwheel ইত্যাদি)।

- **ফ্রেমওয়ার্ক**: React/Vue/Svelte/Next-এর কোনো নিশ্চিত চিহ্ন ব্রাউজারে পড়া যায়নি — SPA এটা নিশ্চিত, ফ্রেমওয়ার্ক অজানা। (গিট রিপো না থাকায় প্যাকেজ তালিকা — package.json — পাওয়ার কোনো পাবলিক পথ নেই।)
- **হোস্টিং**: সাইটের নিজের হোস্টিং কোথাও নাম করা নেই (মিডিয়া CDN = Cloudinary)।
- অ্যানালিটিক্স, লাইসেন্স/ক্রেডিট পেজ: নেই।

## 10. যাচাইয়ের পার্শ্ব-তথ্য (স্বচ্ছতা)
- টেস্ট প্রজেক্ট "New Cartoon Project 1" অ্যাকাউন্টে সেভ অবস্থায় আছে, সব টেস্ট লেয়ার সরিয়ে 0 ট্র্যাকে পরিষ্কার করে রাখা।
- মাইক টেস্টে 13 সেকেন্ডের নীরব রেকর্ডিং Global Audio লাইব্রেরিতে থেকে গেছে (8 → 9টি ফাইল) — লাইব্রেরি অডিও মোছার কোনো বাটন অ্যাপে নেই।
- কোনো পেমেন্ট হয়নি, কিছু পাবলিশ/শেয়ার হয়নি, কোনো সেটিং বদলানো হয়নি।

## 11. আমাদের ক্লোন বানাতে হলে (পরের ধাপের খসড়া)
ওদের স্ট্যাকের পাবলিক অংশটাই আমাদের জন্য যথেষ্ট রোডম্যাপ: PWA (offline-first, service worker) + Firebase (Auth/Google, RTDB/Firestore, স্টোরেজ বিকল্প হিসেবে Cloudinary) + ক্যানভাস-ভিত্তিক 2D এডিটর (লেয়ারড স্প্রাইট, টাইমলাইন, মোশন পাথ, প্রিসেট অ্যানিমেশন) + মাইক রেকর্ডিং (WebM) + ব্রাউজারে ভিডিও এক্সপোর্ট। যেসব জায়গায় ওরা দুর্বল/ফাঁকা — Text টুল, সাবটাইটেল, TTS ভয়েস, স্ক্রিপ্ট জেনারেটর, 9:16 সাপোর্ট — সেগুলো আমাদের সংস্করণে শক্তি হতে পারে।
